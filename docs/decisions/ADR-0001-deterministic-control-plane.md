# ADR-0001：确定性控制平面与 LLM 的边界

状态：Accepted
日期：2026-08-15

## 背景

主动式 Agent 需要生成计划，但 LLM 输出具有不确定性，可能产生非法格式、虚构能力和不适当动作。

## 决定

LLM 只生成结构化候选计划。状态计算、日历、白名单、Schema、权限、预算、幂等、数据新鲜度和风险判断由确定性代码执行。候选计划只有经过 PlanValidator 与 RiskGate 后才能交给 MotorExec。

## 后果

优点：安全边界明确、容易测试、模型可替换、异常可解释。代价：需要维护策略、Schema 和验证器；部分“自主性”受到明确限制。这一限制是产品能力而非缺陷。

## 未选择方案

- 允许 LLM 直接调用工具：风险和审计成本过高。
- 完全不用 LLM：无法覆盖开放式分析和语义命令，但可作为降级路径。
