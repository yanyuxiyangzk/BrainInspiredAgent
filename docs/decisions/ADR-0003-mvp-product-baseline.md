# ADR-0003：MVP 产品基线

状态：Accepted  
日期：2026-08-16

## 背景

需求评审发现目标用户、首个业务闭环、交互方式和通知渠道尚未确定，阻碍 MVP 范围冻结。

## 决定

- 首要用户为本地部署的单人量化研究者。
- 首个闭环为“模拟市场摘要 + 收盘后夜间复盘”。
- MVP 提供 CLI，不开发 WebUI；内部保持可被未来 API 复用的应用服务边界。
- 默认通知实现为本地 NotificationSink；Webhook 属于可选后续适配器。
- MVP 不包含真实证券下单、资金操作、多租户和多机高可用。

## 后果

产品验收可围绕单机可控环境进行，不需要提前设计组织权限、Web 前端和生产通知可靠性。未来增加 Web/API 或外部通知时必须继续经过统一 EventBus、Validator 和 RiskGate，不能形成旁路。
