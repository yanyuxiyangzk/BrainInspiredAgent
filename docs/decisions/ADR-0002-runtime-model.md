# ADR-0002：模块化单体与单一控制事件循环

状态：Accepted
日期：2026-08-15

## 背景

系统需要多个常驻脑区持续运行。过早采用微服务会增加消息可靠性、部署、观测和一致性成本；把所有计算放进单一事件循环又会被阻塞任务冻结。

## 决定

MVP 使用一个主进程和一个 asyncio 控制事件循环。脑区作为受 Supervisor 管理的协程运行。网络 I/O 异步化；阻塞库进入受限线程池；CPU 密集任务进入进程池；超长任务保留迁移外部 Worker 的接口边界。

## 后果

优点：开发部署简单、领域边界仍清晰、容易调试。代价：主进程是单点，内存 EventBus 不跨崩溃持久化。通过数据库状态、Outbox、幂等和恢复扫描控制影响。

## 演进触发条件

- CPU/内存隔离成为稳定性问题；
- 任务持续时间或规模超过进程池适用范围；
- 需要多实例或跨主机扩展；
- 内存总线吞吐或可靠性无法满足 SLO。
