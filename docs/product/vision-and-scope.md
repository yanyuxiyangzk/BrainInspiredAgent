# 产品愿景与范围

状态：Review

最近评审：[MVP 需求评审记录（2026-08-16）](../reviews/requirements-review-2026-08-16.md)

## 产品愿景

BIA 是一个可持续运行的主动式 AI Agent 平台。它能够感知环境、维护目标、受限决策、执行声明式任务，并从历史结果中形成可验证的经验。

首个垂直场景为量化研究与市场监控，但底层架构避免绑定某一行情源或模型供应商。

## 目标用户

- 需要自动化市场观察、研究和复盘的个人量化研究者。
- 需要可审计 Agent 运行底座的工程团队。
- 希望组合行情、回测、LLM 和通知工具的策略开发者。

## 用户价值

1. 无需逐条 Prompt，系统可按时间、环境变化和内部目标主动工作。
2. 每个结论能追溯到感知数据、决策理由、工作流版本和工具结果。
3. 大模型异常或外部服务故障时，系统能拒绝、降级或恢复，而非失控执行。
4. 新业务主要通过注册工具与 Workflow 扩展，不修改脑区核心结构。

## MVP 范围

MVP 包含：

- 单实例持续运行；
- 模拟市场感知和外部命令注入；
- 确定性日历与状态判断；
- 注意力过滤和事件合并；
- LLM 或规则驱动的候选任务计划；
- 白名单 Workflow 校验与执行；
- 工具调用、条件、并行、延迟和子 Workflow；
- SQLite 情景记忆及完整 Trace；
- 报告和模拟通知；
- 夜间复盘与记忆整理；
- 重启恢复、超时、限流、幂等和安全模式。

## MVP 明确不做

- 真实证券下单及资金操作；
- 多租户和商业计费；
- 多机高可用；
- Agent 自行生成并上线可执行代码；
- Agent 自行修改风险策略或权限；
- 未验证经验直接改变生产决策；
- 一开始同时接入 easy-tdx、Qlib、RD-Agent 和多个向量库。

## 成功定义

MVP 在模拟环境连续运行 7 天，满足：

- 计划任务触发成功率不低于 99%；
- 同一幂等键不产生重复副作用；
- 所有任务均能通过关联 ID 还原执行链路；
- 非法 LLM 输出和未知 Workflow 的拦截率为 100%；
- 单个脑区或工具异常不会导致整个主进程无响应；
- 重启后能识别并处理未完成任务；
- 无显著事件时不产生无意义的持续 LLM 调用。

## 产品边界

BIA 是研究与自动化基础设施，不提供收益保证，也不构成投资建议。即使未来增加交易能力，真实下单也必须作为独立高风险能力设计和审批。
